# Gateway Building Info

## Room Numbers

* Rooms X100–X299 are on the Northeast side of the building (facing Hearst Ave).
* Rooms X300–X499 are on the Southwest side of the building (facing into campus).
* The first digit is the floor: 4123 is on Floor 4. Lower Level rooms start with a B.

## Site Features

* Most common keyboard shortcuts, like <kbd>+</kbd> and <kbd>−</kbd> to zoom, should work. Press <kbd>?</kbd> for the full list.
* Press <kbd>1</kbd>–<kbd>5</kbd> to navigate to each floor, or <kbd>B</kbd> or <kbd>L</kbd> for the Lower Level.
* Clicking on a room updates the URL with a direct link to that room.
* **Corrections** (top right) collects notes for the people maintaining the map: pick a room or mark a point with the pencil, write what should change (and whose name is wrong, if a name is), then **Copy all** and paste the list into an issue or hand it to an LLM. The list stays in your browser until you clear it.
