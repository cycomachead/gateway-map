About Gateway Map

An interactive map of the Barbara and Gerson Bakar Gateway building at UC Berkeley, home of CDSS. Click the ‘Info’ button for more about the features of this site.

This site is tested against WCAG 2.2 AA standards. If you have a challenge accessing this site, please write to ball@berkeley.edu.

Made by Michael Ball, with a healthy dose of large language models.

Floor plans are traced from the architects' CAD drawings; faculty office assignments come from the EECS directory. Found a mistake? Open an issue or a pull request on GitHub.
